# Rodokmen

Pracovní repozitář pro tvorbu rodokmenu v Claude Code (cloudové relace).

Skill **rodokmen** je ve složce `.claude/skills/rodokmen/` a Claude Code si ho v relaci nad tímto
repozitářem načte sám.
